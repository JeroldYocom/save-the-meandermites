# Save the Meandermites

A one-finger Android game about guiding tiny, doomed, adorable creatures to safety. Work in progress.

- Engine: Unity 6000.6.7f1 LTS (Universal 2D)
- Gameplay simulation: `Assets/Sim/` - deterministic plain C#, tested with `dotnet test`
- Design: `docs/design/` and the [wiki](https://github.com/JeroldYocom/save-the-meandermites/wiki)
